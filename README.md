Java exercises from the first semester of the Introduction to Programming course.

## Structure

```
primeiro-periodo-introducao-programacao/
├── Lista 01 - Entrada e Saída       (Input and Output)
├── Lista 02 - Entrada e Saída       (Input and Output)
├── Lista 03 - Básico de Condicionais (Basic Conditionals)
├── Lista 04 - Condicionais          (Conditionals)
├── Lista 05 - Condicionais          (Conditionals)
├── Lista 06 - Comandos de Repetição (Loops)
├── Lista 07 - Vetores               (Arrays)
├── Lista 08 - Recursão              (Recursion)
└── Lista 09 - Matrizes              (Matrices)
```

Each folder holds the `.java` files for one exercise list, grouped by topic.

## How to run

Compile and run an exercise individually with the JDK:

```bash
cd "primeiro-periodo-introducao-programacao/Lista 01 - Entrada e Saída"
javac Adicao.java
java Adicao
```
