## Estrutura

```
primeiro-periodo-introducao-programacao/
├── Lista 01 - Entrada e Saída
├── Lista 02 - Entrada e Saída
├── Lista 03 - Básico de Condicionais
├── Lista 04 - Condicionais
├── Lista 05 - Condicionais
├── Lista 06 - Comandos de Repetição
├── Lista 07 - Vetores
├── Lista 08 - Recursão
└── Lista 09 - Matrizes
```

Cada pasta reúne os arquivos `.java` de uma lista de exercícios, agrupados por tópico.

## Como executar

Compile e execute um exercício individualmente com o JDK:

```bash
cd "primeiro-periodo-introducao-programacao/Lista 01 - Entrada e Saída"
javac Adicao.java
java Adicao
```
